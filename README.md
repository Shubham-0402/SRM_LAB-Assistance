# 🧪 SRM LAB Assistance

> An interactive web-based chemistry laboratory assistant designed to help students understand and perform chemistry practical experiments through step-by-step guidance, visual references, observations, and calculations.

---

## 📖 About the Project

**SRM LAB Assistance** is a Flask-based educational web application created to make chemistry laboratory experiments easier to understand and follow.

Instead of relying only on handwritten laboratory manuals, the application provides a structured digital experience where students can explore experiments, follow procedures, refer to visual material, and understand the calculations involved.

The project was developed as a practical application of **Python, Flask, HTML, CSS, and JavaScript**.

---

## ✨ Features

* 🧪 **Multiple Chemistry Experiments**

  * Access a collection of chemistry laboratory experiments from one interface.

* 📋 **Step-by-Step Procedures**

  * Follow the experimental procedure in a structured format.

* 📓 **Visual Laboratory References**

  * Important notebook/reference images are included where required.

* 🧮 **Experiment Calculations**

  * Relevant formulas and calculations are presented alongside the experiments.

* 🔬 **Observation Guidance**

  * Helps students understand the observations associated with practical experiments.

* 💻 **Web-Based Interface**

  * Access the laboratory assistant directly through a browser.

* 📱 **Responsive Interface**

  * Designed to remain usable across different screen sizes.

---

The application currently contains **7 chemistry experiments**.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Shubham-0402/SRM_LAB-Assistance.git
```

### 2. Move into the project directory

```bash
cd SRM_LAB-Assistance
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

### Windows

```bash
venv\Scripts\activate
```

### macOS / Linux

```bash
source venv/bin/activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

Then open the local URL displayed by Flask in your browser.
